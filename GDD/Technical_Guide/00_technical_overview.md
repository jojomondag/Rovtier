# Technical Overview

## 1. Technology Stack
*   **Engine:** Unity 6 (Universal Render Pipeline - URP)
*   **VR Framework:** OpenXR (Cross-platform compatibility)
*   **Networking:** Fish-Net (Networking solution) + Epic Online Services (EOS) for relay and matchmaking.

## 2. Multiplayer Architecture
*   **Topology:** Peer-to-Peer (P2P) with Host-Client model.
*   **Cross-Platform:** PCVR and Standalone VR cross-play support.

## 3. VR Implementation
*   **Physics:** Physics-based interaction for weapons and climbing.
*   **IK:** Full body IK for player avatars to ensure immersion.
*   **Optimization:** Strict performance budgets for standalone headsets (72fps minimum).
