# Community Contribution Guide

## 1. Philosophy: "Open Studio"
Rovtier is built with the community. We accept canon contributions from players, including art, sound, and code.

## 2. Reward Tiers
Contributors earn in-game rewards and recognition:
*   **Scout:** Bug reports, minor feedback. (Reward: Discord Role)
*   **Architect:** Asset creation, significant code fixes. (Reward: In-game cosmetic, Credits)
*   **Warlord:** Major feature implementation, core design contribution. (Reward: NPC named after you, Exclusive skin)

## 3. Workflow
*   **The Hatchery (Art & Sound):** Submit concept art, models, and audio for review.
*   **The Forge (Code):** Submit Pull Requests for bug fixes and features.
